# SemesterDash - Public Documentation

This folder contains public-facing documentation that is safe to share in the open-source repository.

---

## 📂 Files in This Folder

### Design & Development

- **[DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)**
  Complete UI design guidelines including colors, typography, spacing, shadows, and animation principles. Essential reading for anyone contributing to the UI.

- **[LOCALIZATION.md](./LOCALIZATION.md)**
  Internationalization (i18n) guide covering supported languages, RTL support, translation workflow, and best practices for Hebrew/English/Arabic localization.

### Security

- **[SECURITY.md](./SECURITY.md)**
  Public security policy describing how to report vulnerabilities responsibly. This file follows GitHub's standard security disclosure format.

---

## 🎯 Purpose

These documents help:
- **Contributors**: Understand project conventions and standards
- **Designers**: Follow consistent visual language
- **Developers**: Implement features according to guidelines
- **Security Researchers**: Report vulnerabilities properly

---

## 🔒 Private Documentation

Internal documentation (roadmaps, strategy, sensitive info) is kept in `docs/private/` which is not tracked in git.

## 🤝 Contributing

When updating these docs:
1. Keep information **technical and objective**
2. Avoid **personal information** or internal strategies
3. Update **Last Updated** dates
4. Follow **markdown best practices** for readability
